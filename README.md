# TEXT-BASED-SLOT-MACHINE-USING-JS

A simple, interactive text-based slot machine game implemented in JavaScript. This game allows users to deposit money, choose the number of lines to bet on, place bets, and spin the slot machine to win or lose money based on random outcomes.

## Features

- Deposit money to start playing
- Choose between 1 to 3 lines to bet on
- Set your bet per line
- Spin the slot machine with randomly generated symbols
- Winnings based on matching symbols
- Option to play again until the balance is exhausted

## How to Play
1. Clone the repository:
```bash
git clone https://github.com/aridepai17/TEXT-BASED-SLOT-MACHINE-USING-JS.git
```
    
2. Navigate to the project directory:
```bash
cd TEXT-BASED-SLOT-MACHINE-USING-JS
```

3. Install the required dependencies:
```bash
npm install
```

4. Run the game:
```bash
node project.js
```

5. Follow the on-screen instructions to play the game.

## Code Explanation
- The game starts by prompting the user to deposit money.
- The user can choose the number of lines to bet on (1 to 3).
- The user sets the bet amount per line.
- The slot machine generates three random symbols from a predefined set.
- The winnings are calculated based on the number of matching symbols.
- The user can choose to play again or exit the game.
- The game continues until the user runs out of money or chooses to exit.
